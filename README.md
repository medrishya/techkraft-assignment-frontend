## Requirements

- Node.js 20.19+ (or a version supported by your installed Angular CLI)
- npm

## Run

```bash
npm install
npm start
```

In a second terminal, run the included mock API:

```bash
npm run mock:api
```

The mock API listens on `http://localhost:3000`; the Angular app is configured to use it.
Open http://localhost:4200.

## Test

```bash
npm test
```
